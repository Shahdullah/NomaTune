# NomaTune v1.3.28

## Playback signed out — fixed at the actual cause

The v1.3.27 error report identified it exactly:

```
Please sign in [signedIn=false, visitor=true, dataSync=false, poToken=true, sessionPoToken=true, webPoTokens=true]
```

Signed out, but every anonymous request still carried a stale visitor identity and stale PoTokens. YouTube answers
"Please sign in" for that on every client.

- Anonymous resolution now runs with a request that carries **no** cookie, visitor identity, dataSyncId or PoToken,
  and the youtubei.js session itself is created from that same clean request.
- The one-shot anonymous recovery now also clears `visitorData`, which v1.3.27 forgot.

## Songs that reported "No direct audio format"

Some tracks are offered to the anon web client as SABR-only, so no progressive/adaptive audio format is returned.
When that happens the resolver now retries the same track through the fallback clients ArchiveTune ships
(`ANDROID_VR`, `IOS`, `ANDROID`) before giving up.

  background styles **Follow theme / Blur / Acrylic / Glass**.
