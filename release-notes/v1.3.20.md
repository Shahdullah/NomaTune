## v1.3.20 — anonymous playback, round 2

v1.3.19 restored the `MWEB → VISIONOS` fallback, but the resolver only moved on to the
next client when the first one answered `NO_FORMAT` (SABR-only). The failure you actually
hit — *"Confirm playback in YouTube Music"* / code 2000 — is `LOGIN_REQUIRED` (HTTP 401),
so the guard threw before `VISIONOS` was ever tried. Round 2 fixes exactly that.

### Resolver (`morideobfuscator`)

- **Rotation is no longer NO_FORMAT-only.** Any client-attributable failure now moves to the
  next client: `NO_FORMAT`, `LOGIN_REQUIRED`, `UNAVAILABLE`, `DECIPHER`, `HTTP`, `PO_TOKEN`.
  Only transport failures (`NETWORK`, `TIMEOUT`) still abort immediately, because a dead
  connection is not the client's fault.
- **One tokenless retry.** A rejected anonymous PoToken is session-wide: YouTube then answers
  "Please sign in"/403 for *every* anonymous client, so rotation alone can never recover.
  When a token-bearing attempt fails, the session is rebuilt without PoTokens and retried
  once. Identities whose token was rejected are remembered, so the bad token is not replayed
  on later tracks.
- **Honest errors.** The final message now carries every client's reason
  (`MWEB: Please sign in; VISIONOS: …`) instead of a bare "no playable response", so a red
  screen tells us which wall we hit.

### Verification

- `morideobfuscator/javascript/tests/__rotation.test.mjs` — 5/5 pass
  (`NO_FORMAT`, `LOGIN_REQUIRED`, `HTTP 403` → rotate and play; `NETWORK` → no rotation;
  both fail → aggregated message).
- Live end-to-end through the rebuilt bundle with anonymous requests, 5 tracks
  (*Midnight City*, *Bohemian Rhapsody*, *Despacito*, *Adele – Hello*, …): all resolved
  `itag=140/251` and returned **HTTP 206** on a range probe.
- Deliberately corrupted PoToken in the request → the tokenless retry still resolved and
  probed **206**.

Bundle rebuilt from the patched source: `youtubei.bundle.js` contains `without PoToken`
exactly once, plus `VISIONOS`.

Install over v1.3.19 (same signing key, `versionCode 34`).
