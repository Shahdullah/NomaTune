# NomaTune v1.3.27

## Playback signed out: wipe residual state and retry

Every playback file in NomaTune is byte-identical to ArchiveTune, and ArchiveTune's own resolver plays. What can
still differ is the playback state carried over from an earlier session on the same install — a visitor identity, a
PoToken minted for a previous login, or a dead cookie.

- When anonymous resolution is refused (`Please sign in` / 401 / token rejection), the app now clears the residual
  playback state and retries **once** before failing.
- Signing out now clears the in-memory playback auth immediately, not just DataStore, so a signed-out device cannot
  keep sending the previous account's cookie.
- The playback error now carries the real auth shape, e.g.
  `Please sign in [signedIn=false,visitor=false,dataSync=false,poToken=false,sessionPoToken=false,webPoTokens=false]`
  so a screenshot is enough to diagnose the next report.
