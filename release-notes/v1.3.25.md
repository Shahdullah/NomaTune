# NomaTune v1.3.25

## Playback without an account

- The YouTube resolver is now ArchiveTune's own shipped resolver, copied verbatim (single anonymous client, `MWEB`, no client rotation, no token stripping, no visitor rewriting). Only the exported bridge name is NomaTune's.
- Removed every NomaTune-specific change made to the resolver in v1.3.23 and v1.3.24. Those changes forced clients that refuse anonymous playback (`ANDROID_VR`, `IOS`, `ANDROID`, `VISIONOS`) to be tried first, which is what produced `Please sign in` on all five clients.

## Notes

- Signed in and signed out now share the exact code path ArchiveTune uses.
- Everything else is unchanged from v1.3.24.
